# 📧 Spam Mail Prediction

This project demonstrates how to build a **Spam Mail Classifier** using Python, Scikit‑Learn, and TF‑IDF feature extraction. The goal is to automatically classify email/SMS messages as **Spam** or **Ham (legitimate)**.

---

## 🚀 Features
- Text preprocessing with **TfidfVectorizer**
- Training and testing on labeled datasets
- Model building with machine learning algorithms (e.g., Logistic Regression, Naive Bayes)
- Prediction on new/unseen messages
- Simple interface to test custom inputs

---

## 📂 Project Structure
- `Spam Mail Prediction.ipynb` → Jupyter Notebook containing the full workflow
- `.ipynb_checkpoints/` → should be ignored (temporary Jupyter files)
